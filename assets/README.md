# Демонстрационные медиа

`demo.webm` и `demo-poster.png` созданы специально для Party Quiz программной отрисовкой. Видео без звука, 960×540, 6 секунд: фиолетовый круг превращается в жёлтую звезду после 3,2 секунды. Вопрос о продолжении останавливает видео на 3,0 секунды.

Материалы можно свободно использовать и заменять в этом проекте. Команда `pnpm db:seed` копирует их в постоянный `data/uploads`. В редакторе замените ролик собственным, задайте постер и время остановки. Скрипт `scripts/make-demo.ts` позволяет заново создать демонстрационный ролик через установленный Chromium Playwright.

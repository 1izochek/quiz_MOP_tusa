# Проверка Party Quiz

Дата: 1 октября 2026. Среда: macOS ARM64, Node 24.19, pnpm 10.17.1.

## Успешно

- `pnpm lint` и `pnpm typecheck` — без ошибок.
- `pnpm test` — 24 теста: 12 unit и 12 интеграционных.
- `pnpm build` — собраны клиент и сервер.
- `pnpm db:migrate`, повторная миграция и `pnpm db:seed` — выполнены.
- Production Express запущен на `0.0.0.0:3000`, приложение открыто во встроенном браузере.
- Браузерный сценарий через Playwright-локаторы: вход администратора → создание квиза через редактор → изменение вопроса/вариантов → подтверждение автосохранения → старт сессии → вход гостя по ссылке с кодом → вопрос → ответ → обновление страницы и восстановление принятого ответа → раскрытие с 1499 очками → лидерборд → финальный пьедестал. Отдельный экран проектора также показывает финал.
- XLSX с пятью листами и подробный CSV проверены интеграционными тестами.
- Загрузка поддельного PNG и исполняемого файла отклоняется; правильные ответы и очки скрыты до раскрытия; второй token отключает первую вкладку; дедлайн и пауза проверены серверными тестами.
- Собственный WebM длительностью 6 секунд и постер включены локально.

## Нагрузочный прогон

| Метрика | Результат |
|---|---:|
| Одновременные WebSocket подключения | 200 |
| Вопросы | 50 |
| Принятые и сохранённые ответы | 10 000 |
| Отклонённые ответы | 0 |
| Подтверждение p50 | 380 мс |
| Подтверждение p95 | 482 мс |
| Максимум | 558 мс |
| Длительность этапа ответов | 27 с |
| Конечное состояние | ROUND_LEADERBOARD |

Первый burst пришёл в последние две секунды настоящего пятисекундного таймера. Для последующих вопросов время до дедлайна сокращалось непосредственно на тестовом сервере; сетевые запросы и SQLite реальные. Это localhost, а не испытание Wi-Fi на 200 физических телефонах. Найденная ошибка отложенного счётчика при graceful shutdown исправлена; повторный прогон завершился с кодом 0.

## Ограничения проверки

- Повторный запуск интеграционных тестов после нового сообщения пользователя был заблокирован обновившимися сетевыми разрешениями среды (`listen EPERM`); до этого все 24 теста и повторная нагрузка прошли. Это отказ запуска тестового сервера, а не падение игрового сценария. Unit-тесты повторно прошли.
- `pnpm test:e2e` запускался, но самостоятельный Chromium заблокирован sandbox macOS (`MachPortRendezvousServer: Permission denied`) до выполнения теста. Эквивалентный основной сценарий выполнен во встроенном браузере. Отдельный запуск Playwright на обычном компьютере всё ещё требуется.
- Docker daemon не запущен; контейнерный запуск не проверен. Dockerfile и Compose подготовлены.
- Полноценное испытание на реальном проекторе, Safari/iOS и Wi-Fi со 150 гостями не выполнялось. Встроенный браузер не применил запрошенное изменение viewport к скрытой вкладке, поэтому визуальная проверка 390×844 в этой среде не подтверждена. Адаптивные стили и мобильный Playwright-сценарий есть в проекте.
- Проверка звука и синхронного видео на двух физических экранах остаётся частью репетиции перед мероприятием.

Исходники тестов находятся в `tests/`. Эти ограничения не скрыты за успешными результатами других проверок.
